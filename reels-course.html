Lesson 1 · 10 min

Meet your editing assistant

GoalUnderstand what Claude Code does so nothing later feels like magic or a mystery.

Claude Code is Claude with hands. Regular Claude chats with you. Claude Code can also work with the files on your computer: open your video, run editing tools, and save a finished reel into your folder. You describe the edit, it does the work, then tells you what it did.

Behind the scenes it uses two free tools that professionals use:

  • FFmpeg, the video engine. It cuts, crops, adds music, adds text and exports. It has no buttons, only typed commands, which is why most people never touch it. Claude types those commands for you.
  • Whisper, a speech-to-text tool. It listens to your video and writes down every word with timing, which is how you get automatic captions.

How it feels to use

You Cut the pauses out of talking.mp4 and make it vertical for Reels.

Claude Here's my plan: 1) find every pause longer than half a second, 2) cut them out, 3) crop to 9:16 at 1080×1920. I'll save it as talking-reel.mp4 and leave your original alone.

Claude wants to run: ffmpeg -i talking.mp4 -af silencedetect=...Do you want to proceed?  1. Yes  2. Yes, and don't ask again  3. No

You 1

Claude Done. Removed 14 pauses (11 seconds total). Your reel is 38 seconds long: talking-reel.mp4

Lesson 2 · 15 min

Set up in 15 minutes

GoalInstall Claude Code, make a Reels folder, and have Claude install the video tools for you.

Pick your computer:

  1. Open Terminal. Press Cmd + Space, type Terminal, press Enter. A window with a blinking cursor opens. This is where you'll talk to Claude Code.
  2. Install Claude Code. Copy this line, paste it into Terminal, press Enter, and wait for it to finish.
    Paste into Terminal
    curl -fsSL https://claude.ai/install.sh | bash
  3. Make your Reels folder. In Finder, create a folder on your Desktop called Reels. Drag one or two of your video clips into it.
  4. Go into the folder and start Claude. Close Terminal, open it again (so it sees the new install), then paste:
    Paste into Terminal
    cd ~/Desktop/Reels
claude
    The first time, it opens your browser so you can sign in with your Claude account.
  1. Open PowerShell. Click Start, type PowerShell, press Enter.
  2. Install Claude Code. Copy this line, paste it into PowerShell (right-click pastes), press Enter.
    Paste into PowerShell
    irm https://claude.ai/install.ps1 | iex
    If it says it needs Git for Windows, install it from git-scm.com, then close and reopen PowerShell.
  3. Make your Reels folder. In File Explorer, create a folder on your Desktop called Reels and put one or two clips in it.
  4. Go into the folder and start Claude. Close and reopen PowerShell, then paste:
    Paste into PowerShell
    cd $HOME\Desktop\Reels
claude
    If your Desktop is synced to OneDrive and that fails, try cd $HOME\OneDrive\Desktop\Reels. The first launch asks you to sign in.
Prefer not to use a terminal? The Claude desktop app also includes Claude Code. Open it, choose Code, and select your Reels folder. Everything in this course works the same way there.

Your very first message: let Claude install the tools

Once Claude Code is running in your Reels folder, paste this. It checks for FFmpeg and Whisper and installs anything missing.

Paste into Claude Code
I'm a complete beginner and I want to edit Instagram Reels in this folder.
Please check whether FFmpeg and a Whisper speech-to-text tool are installed on my computer.
If anything is missing, tell me in plain English what it is and why I need it, then install it.
When you're done, list the video files in this folder and tell me how long each one is.

Understanding the "Do you want to proceed?" question

Before Claude runs a command or changes a file, it shows you what it wants to do and asks. You'll see three choices:

  • Yes runs it once.
  • Yes, and don't ask again lets that kind of command run without asking. Handy for FFmpeg once you're comfortable.
  • No stops it. You can then type what you'd like instead.
Moving clips from your phone: AirDrop (iPhone to Mac), a USB cable, or Google Drive / Google Photos downloads keep full quality. Sending videos to yourself through text or chat apps compresses them, and they'll look blurry on Instagram.

Lesson 3 · 10 min

Your first edit: trim it and make it vertical

GoalTurn a raw clip into a correctly sized Reel and learn the "ask, watch, adjust" loop.

Reels are tall: 9:16, which means 1080 pixels wide by 1920 tall. If you filmed sideways, Claude crops it. If you filmed vertically, it makes sure the size and format are exactly what Instagram wants.

Replace clip1.mp4 with your file's real name. You can also ask "what videos are in this folder?" if you're not sure.

Paste into Claude Code
Take clip1.mp4 and make it a vertical Instagram Reel:
- Cut off the first 2 seconds (that's me pressing record) and the last 3 seconds.
- Make it 1080x1920 (9:16). If it's horizontal, crop the center.
- Save it as clip1-reel.mp4. Don't change my original file.
Tell me the final length when you're done.

The ask, watch, adjust loop

  1. Ask for the edit.
  2. Watch the new file. Double-click it in your Reels folder, or type "open clip1-reel.mp4".
  3. Adjust in plain words: "trim one more second off the start", "the crop cut off my head, keep the top of the frame instead".

You don't need special words. Talk to it the way you'd talk to a friend helping you edit.

Not sure where the good part starts? Ask: "Show me what's happening at 0, 5, 10 and 15 seconds in clip1.mp4." Claude can grab still frames and look at them, then suggest where to cut.

Lesson 4 · 10 min

Cut the dead air

GoalMake talking videos snappy by removing pauses, and join several clips into one reel.

The fastest way to make a talking reel feel professional is to cut the pauses between sentences. Editors call these quick cuts jump cuts. Doing it by hand takes ages. Claude finds the quiet moments automatically.

Paste into Claude Code
In clip1-reel.mp4, remove every pause longer than 0.5 seconds.
Leave about 0.15 seconds before and after each sentence so the cuts don't feel abrupt.
Save it as clip1-tight.mp4 and tell me how many seconds you removed.

Tune how tight it feels

FeelSay thisGood for
Gentle"remove pauses longer than 1 second"Storytelling, calm or emotional content
Snappy"remove pauses longer than 0.5 seconds"Most talking reels and tips
Tight"remove pauses longer than 0.3 seconds, and the 'ums'"Fast-paced educational content

Joining several clips

Paste into Claude Code
Join intro.mp4, tip1.mp4, tip2.mp4 and outro.mp4 into one vertical reel, in that order.
Make sure they all match in size and sound volume.
Add a quick 0.2 second crossfade between clips.
Save it as joined-reel.mp4.

Keeping your best take

Filmed the same line three times? Claude can read your words (using Whisper) and spot repeats.

Paste into Claude Code
I said some sentences more than once in clip1.mp4 because I messed up.
Transcribe it, show me where I repeated myself, and keep only the LAST version of each repeated sentence.
Show me the list of cuts before you make them.

Lesson 5 · 15 min

Captions people actually read

GoalAdd automatic captions in your font and colors, and fix any wrong words before they're burned in.

Many people scroll with the sound off, so captions keep them watching. Claude does this in two steps: Whisper writes down your words with timings, then FFmpeg draws them onto the video. Captions drawn onto the video are called burned-in captions, and they look the same on every phone.

Step 1: get the transcript and check it

Paste into Claude Code
Transcribe clip1-tight.mp4 with Whisper and save the captions as clip1.srt.
Then show me the full text so I can check the spelling of names and brand words.

Read it. If something is wrong, just say so: "It's Avvy, not Avie, and it's LTLU, not L-T-L-U." Claude fixes the file.

Step 2: style and burn them in

Paste into Claude Code
Burn the captions from clip1.srt into clip1-tight.mp4:
- Show 2 to 4 words at a time, never more than 2 lines.
- Font: Montserrat ExtraBold (download it from Google Fonts if I don't have it).
- White text with a thin black outline.
- Highlight the word being spoken in #C9A84C (gold).
- Place them about 65% of the way down the screen, so Instagram's buttons don't cover them.
Save it as clip1-captioned.mp4.

Caption styles to ask for

StyleSay thisVibe
Clean subtitles"simple white captions, one line, small"Aesthetic, calm, luxury
Word highlight"highlight the spoken word in my brand color"Educational, talking head
One word pop"show one big word at a time with a quick pop-in"High energy, hooks, hype
Boxed"white text in a soft pink rounded box"Cute, easy to read on busy backgrounds
See it without exporting the whole video: "Grab a still frame at 4 seconds from clip1-captioned.mp4 and check whether the captions are readable and inside the safe zone." Claude can look at the image and tell you.

Lesson 6 · 10 min

Music and sound

GoalAdd background music that never drowns out your voice, and make your audio sound clean and even.

Put your music file (for example song.mp3) in your Reels folder first.

Paste into Claude Code
Add song.mp3 as background music to clip1-captioned.mp4:
- Keep the music quiet, around 15% volume, so my voice is clear.
- Automatically lower the music even more while I'm talking (ducking).
- Fade the music in over 1 second and out over the last 2 seconds.
- Make the final loudness about -14 LUFS so it sounds even on Instagram.
Save it as clip1-music.mp4.

Sound fixes worth knowing

  • Background hum or fan noise: "Reduce the background noise in my voice, but don't make it sound robotic."
  • Quiet voice: "Make my voice louder and more even, without clipping."
  • Using a trending sound instead: export your reel with your voice only (or silent), then add the trending audio inside the Instagram app when you post. Instagram's own music library is licensed for Reels; songs you download elsewhere usually aren't.
Music rights: only use music you have permission to use, like royalty-free tracks or music you bought a license for. Unlicensed songs can get your reel muted or taken down.

Hooks, text, color and branding

GoalStop the scroll in the first 3 seconds and make every reel look like it belongs to your brand.

A text hook for the first 3 seconds

Paste into Claude Code
Add the text "3 things I wish I knew before selling digital products" to the first 3 seconds of clip1-music.mp4.
Big bold Poppins font, dark text on a white rounded box, centered in the top third of the screen.
Have it fade out quickly at 3 seconds. Save as clip1-hook.mp4.

Color looks

LookSay this
Warm and cozy"make the colors slightly warmer, like golden hour"
Bright and airy"brighten it a little, soften the shadows, keep skin tones natural"
Moody"add a bit more contrast and lower the saturation slightly"
Fix a dark video"this was filmed in low light, brighten it without making it grainy"

Your logo, speed and an end card

Paste into Claude Code
Using clip1-hook.mp4:
- Put logo.png small in the top-right corner at 80% opacity for the whole video.
- Speed the whole video up to 1.1x, keeping my voice natural (not chipmunky).
- Add a 2-second end card: blush pink background (#F5D6D6) with the text "Comment GUIDE and I'll send it to you" in dark text.
Save as clip1-final.mp4.
Speed tip: 1.1x is barely noticeable but makes you sound energetic. Above 1.25x, voices start to sound rushed.

    Your brand kit and batch editing
    
    
    GoalStop repeating yourself. Save your style once, then edit a whole week of reels with one request.
    

    
    Save your brand kit
    
    
    Claude Code reads a file called CLAUDE.md in your folder every time it starts. Whatever you write there, it remembers: your fonts, colors, caption style, and "always explain things simply". Go to the Reel Builder, open the My brand kit tab, copy it, and paste it into Claude Code. It creates the file for you.
    

    
    Organize your folder
    
    
    
      
    Reels/
    
      
      CLAUDE.md      your brand kit
    
      
      raw/          clips straight from your phone
    
      
      assets/       logo.png, music, fonts
    
      
      finished/     ready-to-post reels
    
    
    
    
    Paste into Claude Code
    Organize this folder for me: create raw, assets and finished folders.
Move my video clips into raw and my logo, music and font files into assets.
Update CLAUDE.md so you always look in those folders from now on.
    

    
    Edit five reels at once
    
    
    Paste into Claude Code
    Edit every video in the raw folder into a Reel using my brand kit in CLAUDE.md.
For each one, show me the transcript first so I can check spelling, then make the reel.
Use a hook that fits what I'm talking about in each video, and show me your hook ideas before adding them.
Save everything in finished, with the same name as the original plus "-reel".
    

    
    Make it one click next time
    
    
    Paste into Claude Code
    Turn the editing steps you just did into a reusable script called make-reel, so next time I can just say "run make-reel on my new clips".
Explain in two sentences how I use it.
    

    
    Batching saves the most time. Film four or five reels in one session, drop them all in raw, and let Claude edit them while you do something else.

    Export, check and post
    
    
    GoalMake sure your reel looks sharp on Instagram and gets posted with a cover and caption.
    

    
    The settings Instagram likes
    
    
    
      
    SettingUse thisWhy
    
      
        
    Size1080 × 1920 (9:16)Fills the whole phone screen
    
        
    File typeMP4, H.264 video, AAC audioThe most reliable upload format
    
        
    Frame rate30 fpsSmooth, and avoids audio drifting out of sync
    
        
    Loudnessabout -14 LUFSNot too quiet, not distorted
    
        
    LengthUp to 3 minutesInstagram's current Reels limit. Shorter often performs better.
    
          
    
    

    
    Run a final check
    
    
    Paste into Claude Code
    Check finished/clip1-reel.mp4 before I post it:
- Is it 1080x1920, H.264, AAC, 30fps, and about -14 LUFS?
- Grab frames at 1 second, the middle, and 2 seconds before the end, and check that no text sits in Instagram's covered areas (top 12%, bottom 20%, right edge).
- Tell me in plain English if anything needs fixing, and fix it if I say yes.
    

    
    Cover image and caption
    
    
    Paste into Claude Code
    From finished/clip1-reel.mp4:
- Save 3 cover image options as JPGs (1080x1920) from moments where my face is clear. Add the hook text in big letters to each.
- Write an Instagram caption from the transcript: a strong first line, 3 short value lines, a call to action, and 5 relevant hashtags. Keep it in my voice: warm, encouraging, simple.
    

    
    Posting
    
    
      
      
    1. Move the finished reel and cover to your phone (AirDrop, Google Drive, or a cable).
      2. 
      
    2. In Instagram, go to Settings → Data usage and media quality and turn on Upload at highest quality.
      3. 
      
    3. Create a Reel, choose your video, add the cover from your camera roll, paste the caption, and post.

    Glossary
    
    
    
      
    Terminal / PowerShell
    The text window where you start Claude Code. You type, it replies.
    
      
    Folder (directory)
    Claude Code works in the folder you started it in. Start it in your Reels folder.
    
      
    FFmpeg
    The free video engine Claude uses to cut, crop, add text, music and export.
    
      
    Whisper
    Free speech-to-text. Turns your voice into timed captions.
    
      
    9:16
    Tall, phone-shaped video. For Reels that's 1080 pixels wide by 1920 tall.
    
      
    SRT file
    A simple text file of your captions and when each one appears. You can edit it.
    
      
    Burned-in captions
    Captions drawn onto the video itself, so they look the same everywhere.
    
      
    Jump cut
    A quick cut that removes a pause, making talking videos feel faster.
    
      
    Ducking
    Music automatically gets quieter while you speak.
    
      
    LUFS
    A loudness measurement. About -14 sounds right on social media.
    
      
    Safe zone
    The middle part of the screen that Instagram's buttons and text don't cover.
    
      
    CLAUDE.md
    A notes file Claude Code reads every time it starts. Your brand kit lives here.
